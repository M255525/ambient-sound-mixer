# 🎚️ 環境音混音桌

13 軌**程式即時合成**的環境音（不使用任何錄音素材），像混音台一樣自己混出讀書、助眠、工作背景音：

- 雨聲、雷聲、海浪、風聲、營火、溪流、鳥鳴、蟲鳴、咖啡廳、打字聲、時鐘、噪音（白／粉紅／棕）、柔和和弦
- 每軌：開關、推桿、特性旋鈕、左右聲道、靜音／獨奏、電平燈；主輸出 VU 表、溫暖度、頻譜、自然變化
- 8 組情境預設、我的混音、分享連結
- 睡眠定時（淡出後停止）、番茄鐘（鐘聲提示、休息時自動調小）
- 匯出 30 秒～5 分鐘**無縫循環 WAV**（影片、直播、Podcast 背景音）

用 `python -m http.server 8883` 開 `index.html`。說明見 `manual.html`。測試：`node tools/test_engine.mjs`。
